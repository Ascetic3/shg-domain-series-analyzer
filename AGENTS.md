# Repository Rules for Codex

- Never add real laboratory data, measurements, sample identifiers, experiment images, notebooks, or logs.
- Never add absolute local paths or user-specific configuration.
- Do not change detector mathematics, formulas, thresholds, or default processing parameters without explicit review.
- Use branches and pull requests for changes; do not work directly on the protected default branch.
- Run the complete test suite before declaring work complete.
- Attach synthetic-data screenshots for GUI changes and inspect them for local or sensitive information.
- Never merge pull requests automatically and never enable auto-merge.
- Preserve scientific disclaimers and candidate terminology in code, documentation, exports, and visualizations.
- Keep generated results, environments, caches, and local overrides out of Git.
- Do not add a license until licensing rights are explicitly confirmed.
